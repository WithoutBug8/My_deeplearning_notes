提示工程(Prompt Engineering)是在不更新模型权重的情况下如何与大模型交互引导其行为获取所需结果的方法，**所以如何写好提示词是一个工程师必不可少的技能** 

**一个好的提示词，甚至能让基础模型的输出效果媲美简单经过微调的模型**

## 技巧及示例

### 1. 详细的描述，描述的越清晰模型越懂你的想法

**原理**：详细的描述可以帮助模型更好地理解任务上下文、期望输出格式和约束条件。

**示例**：

```python
from langchain_openai import ChatOpenAI
from langchain.schema import HumanMessage

# ❌ 不够详细的描述
llm = ChatOpenAI(model="gpt-4")
response = llm.invoke([HumanMessage(content="写一个邮件")])
print(response.content)
# 输出可能过于通用，不符合具体需求

# ✅ 详细的描述
detailed_prompt = """
请为我写一封专业的商务邮件，用于回复客户关于项目延期的咨询。

要求：
- 语气：专业、诚恳、友好
- 格式：标准商务邮件格式（主题、称呼、正文、结尾）
- 内容要点：
  1. 对延迟表示歉意
  2. 说明延期的原因（技术难题）
  3. 给出新的预计完成时间
  4. 提供补偿方案（免费延长一个月服务）
- 长度：300-400字
- 语言：中文
"""

response = llm.invoke([HumanMessage(content=detailed_prompt)])
print(response.content)
```

### 2. 让模型充当某种角色

**原理**：角色扮演可以让模型以特定视角和专业知识来回答问题，提高回答的准确性和相关性。

**示例**：

```python
# ❌ 普通提问
normal_prompt = "如何优化数据库查询性能？"
response = llm.invoke([HumanMessage(content=normal_prompt)])
print(response.content)
# 回答可能比较通用

# ✅ 角色扮演
role_prompt = """
你现在是一位有10年经验的资深数据库架构师，专门从事MySQL和PostgreSQL性能优化工作。
你曾经帮助过多家大型互联网公司解决过复杂的数据库性能问题。

请以你的专业视角回答以下问题：
如何优化数据库查询性能？

请从以下几个方面提供深入的建议：
1. 索引设计和使用
2. 查询语句的编写技巧
3. 数据库配置调优
4. 架构层面的优化方案
5. 监控和诊断工具的使用

用专业但易懂的语言解释，避免过于学术化。
"""

response = llm.invoke([HumanMessage(content=role_prompt)])
print(response.content)
```

### 3. 使用分隔符表明输入的不同部分

**原理**：分隔符可以帮助模型清晰地区分指令、输入数据和输出要求，减少混淆。

**示例**：

```python
# ❌ 没有分隔符，容易混淆
no_separator_prompt = """
总结以下文本：这篇文章介绍了人工智能的发展历史，
从1956年的达特茅斯会议开始，到现在的深度学习革命。
机器学习算法可以分为监督学习、无监督学习和强化学习。
深度学习是机器学习的一个重要分支，基于神经网络。
然后提取其中的关键词。
"""
# 模型可能不清楚哪里是输入文本，哪里是任务指令

# ✅ 使用分隔符
separator_prompt = """
任务：请完成以下两个子任务

### 任务1：总结文本
输入文本：
```
这篇文章介绍了人工智能的发展历史，从1956年的达特茅斯会议开始，
到现在的深度学习革命。机器学习算法可以分为监督学习、无监督学习和强化学习。
深度学习是机器学习的一个重要分支，基于神经网络。
```

要求：用3-5句话概括文章主要内容。

---

### 任务2：提取关键词
基于上面的文本，提取3-5个最重要的关键词。
"""

response = llm.invoke([HumanMessage(content=separator_prompt)])
print(response.content)
```

### 4. 对任务制定步骤，设置步骤1，步骤2......

**原理**：将复杂任务分解为多个步骤，可以帮助模型逐步完成，提高输出的完整性和准确性。

**示例**：

```python
# ❌ 直接要求完成复杂任务
complex_task = "分析这个产品的用户反馈并给出改进建议"
# 输出可能不够系统化

# ✅ 分步骤进行
step_by_step_prompt = """
请按照以下步骤分析产品用户反馈并给出改进建议：

【产品】：某在线学习平台
【用户反馈数据】：
- "课程搜索功能很难用，找不到想要的课程"
- "视频播放经常卡顿"
- "客服回复太慢了"
- "希望能有离线下载功能"
- "移动端APP界面不够友好"

### 步骤1：问题分类
请将上述用户反馈按功能模块分类（如：搜索功能、播放功能、客户服务、移动端等）

### 步骤2：问题严重程度评估
为每个问题评估严重程度（高/中/低），并简要说明理由

### 步骤3：根因分析
分析每个问题可能的原因

### 步骤4：改进建议
针对每个问题提出具体的改进建议

### 步骤5：优先级排序
根据影响范围和实施难度，将改进建议按优先级排序（P0/P1/P2）

请严格按照以上步骤输出，每个步骤都要有明确的标题。
"""

response = llm.invoke([HumanMessage(content=step_by_step_prompt)])
print(response.content)
```

### 5. 提供一个例子，类似于few-shot learning

**原理**：提供示例可以让模型通过类比理解任务模式，显著提高输出质量，特别是对于格式化任务。

**示例**：

```python
# ❌ 没有示例
no_example_prompt = """
将以下电影信息转换为JSON格式：
电影名：《肖申克的救赎》，导演：弗兰克·德拉邦特，年份：1994，评分：9.7
"""
# 输出的JSON格式可能不符合预期

# ✅ 提供示例（Few-shot Learning）
few_shot_prompt = """
任务：将电影信息转换为JSON格式

示例1：
输入：电影名：《肖申克的救赎》，导演：弗兰克·德拉邦特，年份：1994，评分：9.7
输出：
```json
{
  "title": "肖申克的救赎",
  "director": "弗兰克·德拉邦特",
  "year": 1994,
  "rating": 9.7
}
```

示例2：
输入：电影名：《盗梦空间》，导演：克里斯托弗·诺兰，年份：2010，评分：9.3
输出：
```json
{
  "title": "盗梦空间",
  "director": "克里斯托弗·诺兰",
  "year": 2010,
  "rating": 9.3
}
```

现在请处理：
输入：电影名：《阿甘正传》，导演：罗伯特·泽米吉斯，年份：1994，评分：9.5
输出：
"""

response = llm.invoke([HumanMessage(content=few_shot_prompt)])
print(response.content)
```

### 6. 使用参考文本，降低模型的幻觉

**原理**：提供相关参考文本可以让模型基于事实回答，减少虚构信息，提高准确性。

**示例**：

```python
# ❌ 没有参考文本
no_reference_prompt = """
介绍一下LangChain框架的主要特点和功能。
"""
# 模型可能产生幻觉，信息可能过时或不准确

# ✅ 提供参考文本
reference_prompt = """
请基于以下参考文本回答问题，不要使用文本之外的信息。

### 参考文本：
LangChain是一个用于构建由语言模型(LLM)驱动的应用程序的开发框架。

主要组件包括：
- Models：提供对各种语言模型的统一接口，如OpenAI、Anthropic、HuggingFace等
- Prompts：管理模型输入，包括提示词模板和输出解析器
- Memory：维护对话上下文和状态
- Indexes：集成外部数据源，如文档加载器和向量数据库
- Chains：将多个组件组合成完整的应用流程
- Agents：让模型自主决定使用哪些工具完成任务

核心功能：
1. 快速集成不同的LLM提供商
2. 构建复杂的提示词管理流程
3. 实现对话记忆功能
4. 连接外部数据和知识库
5. 创建可组合的应用链路
6. 实现自主决策的智能代理

### 问题：
请介绍一下LangChain框架的主要特点和功能，并说明它适合用于什么样的应用场景。
"""

response = llm.invoke([HumanMessage(content=reference_prompt)])
print(response.content)
```

## 额外技巧：思考链(Chain of Thought)

**原理**：让模型展示思考过程，可以提高复杂推理任务的准确性。

**示例**：

```python
# ❌ 直接要求答案
direct_prompt = """
如果我有3个苹果，又买了5个苹果，吃掉了2个，然后给了朋友1个，我现在有几个苹果？
"""

# ✅ 要求展示思考过程
cot_prompt = """
请逐步思考以下问题，并展示你的推理过程。

问题：如果我有3个苹果，又买了5个苹果，吃掉了2个，然后给了朋友1个，我现在有几个苹果？

请按照以下格式回答：
1. 初始状态：
2. 第一次变化：
3. 第二次变化：
4. 第三次变化：
5. 最终答案：

确保每一步的计算都清晰可见。
"""

response = llm.invoke([HumanMessage(content=cot_prompt)])
print(response.content)
```
