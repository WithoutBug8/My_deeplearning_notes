# 🐧 Linux 文件目录总结(从入门到放弃)

---

# 🌳 一、Linux 目录结构（核心理解）

## 🧠 和 Windows 的区别

| Windows     | Linux      |
| ----------- | ---------- |
| 多个磁盘（C盘 D盘） | 只有一棵树      |
| 分区独立        | 全部挂在 `/` 下 |

👉 Linux 是：

> **一棵“倒着的树”，所有东西从根目录 `/` 开始**

---

## 📌 常见目录（必须记）

```
/
├── bin
├── etc
├── home
├── root
├── usr
├── lib
├── dev
├── mnt
├── boot
└── tmp
```

---

## 🧭 每个目录是干嘛的

| 目录      | 作用             |
| ------- | -------------- |
| `/bin`  | 常用命令（ls、cp、rm） |
| `/etc`  | 配置文件（很重要）      |
| `/home` | 普通用户目录         |
| `/root` | 管理员目录          |
| `/usr`  | 程序和软件          |
| `/lib`  | 库文件            |
| `/dev`  | 设备文件           |
| `/mnt`  | 挂载点            |
| `/boot` | 启动相关           |
| `/tmp`  | 临时文件           |

---

# 📍 二、路径（超级重要）

## 1️⃣ 绝对路径

👉 从 `/` 开始

```bash
/home/user/main.c
```

---

## 2️⃣ 相对路径

👉 从当前目录开始

```bash
./main.c
../main.c
```

---

## 🎯 必记符号

| 符号   | 含义   |
| ---- | ---- |
| `/`  | 根目录  |
| `.`  | 当前目录 |
| `..` | 上一级  |
| `~`  | 家目录  |

# 📂 四、Linux 文件类型

👉 Linux：**一切皆文件**

---

## 常见类型

| 类型   | 标志        |
| ---- | --------- |
| 普通文件 | `-`       |
| 目录   | `d`       |
| 链接   | `l`       |
| 管道   | `p`       |
| 设备   | `b` / `c` |
| 套接字  | `s`       |

---

👉 示例：

```bash
-rw-rw-r--
```

第一个字符：

* `-` → 普通文件
* `d` → 文件夹

# 🔐 五、文件权限（重点！！！）

## 📌 权限结构

```
rw-rw-r--
│ │ │
u g o
```

| 类别 | 含义          |
| -- | ----------- |
| u  | 用户（owner）   |
| g  | 组（group）    |
| o  | 其他人（others） |

---

## 📌 权限含义

| 符号 | 含义 | 数值 |
| -- | -- | -- |
| r  | 读  | 4  |
| w  | 写  | 2  |
| x  | 执行 | 1  |
| -  | 无  | 0  |

---

## 📌 示例解析

```bash
rw-rw-r--
```

👉 分三组：

```
rw- | rw- | r--
 u     g     o
```

👉 转成数字：

```
6   6   4
```

👉 所以：

```bash
chmod 664 file
```

---

# ⚙️ 六、修改权限 chmod

---

## 1️⃣ 字母方式（直观）

```bash
chmod u+w file    # 给用户加写权限
chmod g-x file    # 移除组执行权限
```

---

## 2️⃣ 数字方式（最常用🔥）

```bash
chmod 777 file
```

👉 含义：

```
7 = rwx = 4+2+1
```

---

## 常见权限组合

| 数字  | 含义      |
| --- | ------- |
| 777 | 全权限（危险） |
| 755 | 常用于程序   |
| 644 | 常用于普通文件 |

---

# 🧠 七、底层原理（你可以稍微理解一下）

👉 权限其实是：

```
二进制位
```

比如：

```
rwx = 111
rw- = 110
```

👉 系统用位运算判断权限（非常快）

# ⚠️ 八、你必须注意的点

### ❗1. Linux 不看扩展名

* `.txt` `.c` 没意义
* 看权限和类型

---

### ❗2. 执行权限很重要

👉 没有 `x`：

* 程序不能运行

```bash
  # 常见的指令授予权限
  chmod + x 文件名
```

---

### ❗3. 权限不对 → 程序直接挂
