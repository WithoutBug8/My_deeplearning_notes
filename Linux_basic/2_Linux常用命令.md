# 🐧 Linux 常用命令总结（从入门到放弃）

## 🧭 一、路径与目录操作

### 1. `pwd` —— 查看当前路径

* 显示当前所在目录的**绝对路径**
* 类似：你现在“在哪个文件夹里”

```bash
pwd
```

---

### 2. `cd` —— 切换目录

* 进入指定目录（支持**绝对路径 / 相对路径**）

```bash
cd /home/user      # 绝对路径
cd ../             # 返回上一级
cd                 # 回到家目录（~）
```

👉 **重点**

* 不加参数 → 默认回到家目录

---

### 3. `ls` —— 查看目录内容

* 列出当前目录下的文件和文件夹

```bash
ls
ls -l   # 详细信息
ls -a   # 显示隐藏文件
```

---

## 📚 二、查看帮助

### `man` —— 查看命令手册

* Linux 官方说明书（非常重要）,`man`后面接指令可以查看指令的参数如何使用的

```bash
# 比如这个查看ls后面参数的说明书
man ls
```

👉 遇到不会的命令 → 第一时间用 `man`

---

## 📁 三、创建与删除

### 1. 创建文件 / 目录

#### `touch` —— 创建文件

```bash
touch file.txt
```

#### `mkdir` —— 创建目录

```bash
mkdir folder
```
#### `nano` —— 编辑文件(1)

```bash
# 假设新创建了一个test.txt文件，使用nano进行编辑

nano test.txt

# 进去以后一通编辑，编辑完成以后

Ctrl + O   #保存
Enter      #确认
Ctrl + X   #退出
```

#### `vim` —— 编辑文件(2)

```bash
# 假设新创建了一个test.txt文件，使用vim进行编辑

vim test.txt

# 1. 按 i 进入编辑模式
# 2. 进去以后一通编辑，编辑完成以后，按ESC推出编辑模式
# 3. 想要保存
    :wq    # 保存并退出
    :q!    # 强制退出（不保存）

```
---

### 2. 删除

#### `rmdir` —— 删除空目录

```bash
rmdir folder
```

⚠️ **只能删除空目录**

---

#### `rm` —— 删除文件 / 目录（通用）

```bash
rm file.txt        # 删除文件
rm -r folder       # 删除目录（递归）
rm -rf folder      # 强制删除（危险⚠️）
```

👉 实际常用：`rm -r`

---

## 📦 四、复制 & 移动

### 1. `cp` —— 复制文件

```bash
cp file1 file2          # 复制文件
cp file1 dir/           # 复制到目录
cp -r folder1 folder2   # 复制目录
```

👉 **重点坑点**

* 如果目标不存在 → 可能会被当成“新文件名”
* 建议写完整路径，避免误操作

---

### 2. `mv` —— 移动 / 重命名

```bash
mv file1 dir/       # 移动文件
mv old.txt new.txt  # 重命名
```

👉 本质：

* 跨目录 = 移动
* 同目录 = 重命名

---

## 🔍 五、查找文件

### `find` —— 搜索文件

```bash
find /path -name filename
```

---

### 常用用法

#### 1. 查找所有内容

```bash
find .
```

#### 2. 查找文件

```bash
find . -type f
```

#### 3. 查找目录

```bash
find . -type d
```

#### 4. 指定目录查找

```bash
find /home/user -name file.txt
```

---
👉 Linux核心思想：

> **一切通过命令控制**

---

## ⚠️ 六、容易踩坑总结

### ❗1. `rmdir` 不能删非空目录

👉 用：

```bash
rm -r
```

---

### ❗2. `cp` 目标路径错误

```bash
cp file 2509
```

👉 如果 2509 不存在 → 会创建一个叫 2509 的文件 ❗

---

### ❗3. `rm -rf` 非常危险

👉 删除后**无法恢复** 一般情况下千万别用

---
