# 🐧 Yazi 文件管理笔记（从入门到放弃）

---

# 一、核心思维

Yazi 的逻辑：

> 选中 → 操作（copy / delete / rename / search）

---

# 二、文件操作（CRUD 核心）

---

# 1. 增（Create 新建）

## 新建文件 / 文件夹

```text
a
```

输入：

* `test.txt` → 创建文件
* `folder/` → 创建文件夹

---

# 2. 查（Read 查找 / 搜索）

## 查找（当前目录）

```text
/   输入关键词
n   下一个
N   上一个
```

---

## 搜索（更强）

```text
s   按文件名搜索
S   按内容搜索（类似 grep）
```

---

## 过滤（筛选文件）

```text
f
```

示例：

* 输入 `.py` → 只显示 Python 文件

---

# 3. 改（Update 修改）

---

## 重命名

```text
r
```

支持：

* 单文件重命名
* 批量重命名

---

## 复制 / 移动

### 复制

```text
y   复制
p   粘贴
```

---

### 移动

```text
x   剪切
p   粘贴
```

---

### 覆盖粘贴

```text
P
```

---

# 4. 删（Delete）

```text
d
```

---

## 永久删除

```text
D
```

# 五、进阶查找

---

## 快速跳转目录

```text
z   模糊跳转（fzf）
Z   历史目录跳转（zoxide）
```

---

## 1. z（fzf 模糊查找）

在当前目录及子目录中搜索

```text
z → 输入关键词 → Enter
```

特点：

* 支持模糊匹配
* 不需要完整名称
* 适合查找文件

示例：

```text
dl → DeepLearning / data_loader
```

---

## 2. Z（zoxide 智能跳转）

根据使用频率跳转目录

```text
Z → 输入关键词 → Enter
```

特点：

* 记录访问历史
* 常用目录优先
* 支持跨目录跳转

---

## 3. z 与 Z 对比

| 功能  | z（fzf） | Z（zoxide） |
| --- | ------ | --------- |
| 范围  | 当前目录   | 全局历史      |
| 智能性 | 无      | 有         |
| 用途  | 查找文件   | 跳转目录      |

---

## 4. 常用组合

### 定位文件并操作

```text
z → 查找
Space → 选中
y / x → 操作
```

---

### 跨目录复制

```text
1. z → 找文件
2. y → 复制
3. Z → 跳目录
4. p → 粘贴
```

---

### 快速切换项目

```text
Z → 输入项目名 → Enter
```

---

## 注意

* `z` 依赖 fzf
* `Z` 依赖 zoxide
* 需要多使用 `cd` 让 zoxide 记录路径

---

## 一句话理解

z：查当前目录
Z：跳常用目录

# 六、和 Linux 命令对比

| 操作  | Linux         | yazi      |
| --- | ------------- | --------- |
| 创建  | touch / mkdir | a         |
| 查找  | find / grep   | / / s / S |
| 复制  | cp            | y + p     |
| 移动  | mv            | x + p     |
| 删除  | rm            | d / D     |
| 重命名 | mv            | r         |
