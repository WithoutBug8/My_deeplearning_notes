# AI Agent 原理全解析：从“口令”到“目标”

## 1. 什么是 AI Agent？

### 定义转向

- 传统 AI：指令驱动（一个口令一个动作）
- AI Agent：目标驱动（Goal-oriented）
    - 人类只提供目标
    - AI 自主寻找达成路径

### 运作机制

Agent 在一个循环中运行：
`Observation → Action → 改变环境 → 新的 Observation → ...（直到达成目标）`

### 技术演变

- **早期（RL 时代）**
    - 使用强化学习（Reinforcement Learning）
    - 典型例子：AlphaGo
    - 缺点：
        - 模型参数固定
        - 每个任务需要重新训练

- **现代（LLM 时代）**
    - 使用大语言模型（LLM）作为“Agent 大脑”
    - 利用语言生成能力驱动行为
    - 优点：
        - 通用性强
        - 无需重新训练参数

## 2. 核心能力一：根据经验调整行为（Memory）

### 核心思想

- Agent 通过“记忆 + 上下文”学习
- 不依赖重新训练模型参数

### 避免“超忆症”（Hyperthymesia）

- 记录所有细节 → 计算成本极高
- 干扰抽象能力
- 需要高效的记忆管理机制

### 记忆模块设计

#### 1）读（Read）

- 类似 RAG（Retrieval Augmented Generation）
- 从长期记忆中检索相关信息

#### 2）写（Write）

- Agent 自我判断：
    - “这件事是否值得记录？”
- 过滤无关信息

#### 3）反思（Reflection）

- 对记忆进行抽象总结
- 可构建：
    - 知识图谱（Knowledge Graph）
- 用于推理与洞察（如用户偏好）

### 实验发现

- 正面反馈 > 负面反馈
    - “告诉 AI 该做什么”更有效
    - 比“不要做什么”更能引导行为

---

## 3. 核心能力二：使用工具（Tool Use / Function Calling）

### 工具的本质

- 工具 = 函数（Function）
- Agent：
    - 不需要理解内部实现
    - 只需要会调用

### 实现方式

- 在 System Prompt 中定义：
    - 工具用途
    - 调用格式（如特定标记）
- 开发者负责：
    - 将模型输出 → 转换为真实程序执行
- System Prompt会在一开始就加载进入model，如果user prompt与system prompt产生冲突了，系统会优先考虑system prompt

### 工具管理与创造

#### 工具筛选

- 工具过多时：
    - 将说明存入记忆库
    - 动态选择最合适工具

#### 工具生成

- Agent 可：
    - 自动编写代码（函数）
    - 存入工具库复用

### 内外部知识冲突

- 内部：模型已有知识（先验）
- 外部：工具提供信息

### 信任偏向（实验观察）

Agent 更倾向相信：

- 其他 AI 生成内容
- 更新的信息（2025年的信息比2020年的信息更有说服力，尽管2025年的信息是错误的）
- 大模型调用视觉工具再分析网页的时候，排版更专业/美观的内容 可能会被Agent更容易相信

## 4. 核心能力三：制定与执行计划（Planning）

### 问题背景

- 环境复杂且不确定：
    - 广告弹窗
    - 对手行为
- Agent 需要动态调整策略

### 强化规划能力的方法

#### 1）搜索（Search）

- 在“脑中”尝试多条路径
- 自问自答 + 打分
- 剔除低质量方案
- 选择最优路径

#### 2）世界模型（World Model）

- 在“脑内模拟环境”
- 预测行动后果
- 避免现实错误（如误下单）

#### 3）推理模型（Reasoning Models）

- 例如：
    - OpenAI o1
    - DeepSeek R1
- 特点：
    - 长链思考（Chain-of-Thought）
- 本质：
    - 路径搜索 + 自我验证

---

## 5. 当前的局限与挑战

### 1）过度思考（Overthinking）

- 推理能力强 → 行动力下降
- 可能出现：
    - 一直模拟不执行
    - 过度复杂化问题
    - 直接放弃任务

### 2）效率权衡

- 工具调用 ≠ 一定更快
- Agent 需要判断：
    - 什么时候直接推理
    - 什么时候使用工具

### 3）幻觉问题（Hallucination）

- 即使使用 RAG：
    - 仍可能混淆信息来源
- 典型问题：
    - 同名人物混淆
    - 错误信息融合
